# 每秒删帧与自定义水印

入口：左侧「视频与配音 → 视频处理」。导入视频或选择已保留媒体的素材，不需要先转录。

## 操作

1. 选择视频，检查分辨率、时长和帧率。
2. 设置「每秒删除帧数」。例如基准 30 fps、每秒删除 6 帧，输出为 24 fps。设为 0 可单独添加水印。
3. 选择文字或图片水印，调整位置、大小、颜色和透明度；图片支持 PNG、JPEG、WebP。
4. 播放原视频定位画面，生成实际水印效果图，确认后开始导出。
5. 在任务中查看进度、取消或下载结果。成功结果同时进入切片库，原文件不覆盖。

## 处理规则

- 每秒均匀删除指定数量的画面，重新安排保留画面的时间戳。保持整段时长和声音节奏，不加速音频。
- 不足一秒的结尾按实际时长结束，截短最后一帧的显示时间，避免低帧率把短片结尾拉长。视频的整体平均帧率可能因此略有不同。
- 输出为 H.264/AAC MP4。删帧和烧录水印需要重新编码，不能称为无损导出。
- 非整数帧率和可变帧率素材按页面显示的整数基准帧率处理；「每秒删除 N 帧」指这一基准。最低保留 1 帧/秒。删得越多，画面越不流畅。
- 水印的位置比例针对可放置区域，大小按视频高度计算；实际效果图与导出使用同一水印渲染方式。
- 原视频、处理结果独立保存。退出时停止未完成的导出，重启后标记为中断，不把半成品当成功结果。
- 这是本地素材编辑与品牌署名工具，不预测或保证平台的原创、重复内容审核结果。

REA 覆盖的主进程产物中，`captureFrames` 根据时间区间构建 FFmpeg 命令，以 `image2` 写出图片，并处理进度。它证明的是抽图实现，不是用户要求的「每秒删 N 帧并保留时长」。另外用普通 ASAR 读取工具对 renderer 的定点检查发现，其 Decimate 功能围绕保留关键帧、丢弃非关键帧并重设时间戳；这部分属于补充静态证据，不算 REA 已覆盖的语义图。

因此，Lulu 借鉴「明确帧率、预览效果、后台任务、独立导出」的流程，自行实现基准帧率归一化、均匀删帧、保时长、水印渲染和取消恢复。没有将 LosslessCut 的关键帧抽取称作等价功能。

完整原始证据与下载产物位于本机忽略目录 `.test-data/video-workshop-research/`，不会随仓库发布。回归验证使用合成视频和隔离数据目录，不修改用户真实素材。
