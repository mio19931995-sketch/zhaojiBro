# 已知问题与功能范围

更新日期：2026-10-26（0.2.0）。本项目为开发预览版。以下分别记录本批已完善的功能、仍存在的限制和真实环境验收范围。Lulu 4.3.1 同步依据及平台差异见 [同步记录](UPSTREAM_SYNC.md)。

## 本批已完善

- 只下载素材后可在提取页点击“开始转录”；重转录会清除纯下载标记，复用已下载媒体，原文历史可恢复。
- 主页采集的下载、转录、暂停、移除、导出与计数统一限定当前筛选下的选中项；隐藏选中仍保留但不参与当前请求。
- 没有媒体时解释播放/抽帧限制并引导现有设置，纯文稿仍可复制到 Codex；不改媒体保留默认值。
- AI 文稿工作区支持独立草稿、会话、取消/重试、对照、另存与版本保护应用；编辑后文稿库搜索自动刷新。
- AI 工作区新增片段处理、只读引用、逐项采纳/忽略及最近采纳撤销；文稿或引用过期时拒绝覆盖，采纳后仍需保存文稿。详见 [Agent 同步记录](AGENT_SYNC_PHASE2.md)。
- 抖音直播工作区支持监控、分段录制、互动记录、恢复与素材库导入；Windows 进程退出与本地合成视频已验证。
- 四款主力 Windows 转录选择及旧模型保留；新增 GGUF 使用独立原生运行器，发言人编号随字幕保存。未自动下载模型权重。

- 配音正文、音色和语速按来源分别保存草稿，切页或重新打开后可以恢复；生成结果记录来源文稿、音色和语速。
- 全文按原顺序保留每行一句时，校正后可保留字幕时间戳。增删句子导致行数改变会阻止直接覆盖，可另存口播稿并保留原字幕。
- 编辑、重新转录前保留文稿历史版本，提供预览和恢复；恢复前的当前状态同样保留。
- 左侧回收站支持单项和批量恢复，源文件保留，没有永久删除入口。
- 播放时当前字幕置顶；手动滚动或编辑暂停跟随，可回到当前句，并支持单句循环、播放倍速。
- 素材库批量操作限定为当前可见的选中项，切换搜索或文件夹会清空选择。带媒体的素材优先定位媒体文件。
- DeepSeek 密钥管理网页被误当成接口导致的 HTTP 405 已修复：保存及调用时规范化地址，完整 `/chat/completions` 地址也不会重复追加。
- Agnes AI 文本模型快捷配置已接入，默认 `agnes-3.0-flash`，可选择 2.5 或填写其他可用模型；支持固定短句连接测试和按服务隔离保存密钥。

## 使用中需要注意

| 问题 | 当前行为 / 临时用法 |
|---|---|
| 新增 GGUF 模型需用户准备 | 三个新增 GGUF 的运行器已通过 Windows CPU ABI 验证，权重未下载。实际识别质量、长音频耗时与 MOSS 发言人准确率仍待对应权重验证。 |
| SenseVoice 没有字幕时间轴 | 只生成完整文稿；不会伪造分段时间戳。需要同步高亮或 SRT 时请选择 Whisper 或 MOSS。 |
| 直播平台真实环境 | 协议与登录适配已接入，隔离测试不代表真实直播/弹幕成功；网络、平台限制与账号状态仍需真机验证。 |
| 单篇链接未去重 | 重复粘贴同一个链接会产生重复任务；主页采集有独立的去重逻辑。 |
| 批量操作每次最多 1000 条 | 主页采集上限虽然可选 10000 条，下载、导出等仍需分批选择。 |
| 文本服务兼容性 | 当前按 OpenAI Chat Completions 协议调用，提供地址校验、错误提示及独立连接测试，尚未适配所有服务协议。保存配置不代表已完成认证；连接测试通过也不代表所有模型权限和长文处理均已验证。 |
| Agent 引用和上下文上限 | 每个对话最多 8 条引用、合计 16000 字符；超出时明确拒绝，不截断。上下文仍使用最近 10 条消息，尚未迁移自动压缩、工具调用或技能管理。 |
| AI 建议是文本差异 | 根据模型返回正文生成精确范围差异，仍需用户核对含义。采纳只修改草稿；保存后需通过历史版本恢复。改变字幕换行结构的建议会被拦截，可另存输出。 |
| 字幕校稿不会重新对齐音频 | 保留的是原段落时间戳，全文校稿需保持一行一句及原有顺序；仅行数相同不代表大幅改写后的文字仍与语音匹配。大幅改写请另存口播稿。 |
| 高亮跟随不等于自动纠错 | 高亮按现有字幕起止时间定位。错别字、人名、数字与术语仍需人工核对；文案处理的“错字校正”是独立全文模型处理，不会自动逐段回填字幕。 |
| 中英翻译输出为独立文本 | 当前不保留原视频字幕时间轴，不能直接生成同步双语 SRT；摘要、改写和大纲默认提示词面向中文内容。 |

## 尚未实现

- 音色克隆 / IndexTTS2：目前使用 Windows 系统语音。
- 生成配音前的短句试听：目前需生成 WAV 后在音频库播放。
- 双语时间轴翻译、逐段 AI 校对回填：目前中英翻译生成独立文稿。
- 按字幕选句切片和随切片导出对齐字幕：目前切片输入开始、结束秒数。
- 自动选取精彩片段：直播可录制和回放，切片仍按起止时间操作。
- 真正从识别中断点续接：可以复用已下载文件，但重新开始会重新识别整段。
- 托盘后台运行：关闭主窗口会结束此次启动的后端。
- 独立安装器、自动更新、一键资料库备份及整库恢复。已有回收站和文稿历史版本，但不能替代完整资料库与媒体文件备份。

## 真实环境验收范围

- 2026-10-26 用实际 Windows Electron、隔离合成文稿和本地 HTTP 模型验证了片段引用/精确定位、逐项采纳/忽略/撤销、版本冲突和小窗口可用性，5 类检查通过。新增后台 28 项保护回归，全量 213 项通过；旧桌面工作流 5 组通过。详情见 `docs/AGENT_SYNC_PHASE2.md`。真实云端输出质量仍待验证。
- 2026-10-25 用实际 Windows Electron、隔离资料库与本地模拟文本服务验证了新工作区的草稿跨页、简体生成、对照、原文应用/历史版本、输出库跳转、合成直播回放及导入、四款模型目录。脚本为 `tests/upstream-workflow.mjs`，不使用真实账号、平台直播或新 GGUF 权重。
- 原有创作者界面 13 条流程、JEV 检查界面 8 条流程及真实 MCP SDK 只读抽帧回归通过。测试使用合成音视频，不代表识别质量、Codex 指定项目续接或真实平台采集已验收。

- 本地导入、真实中文语音转录、逐段编辑、常用导出、Windows 系统配音、本地切片及系统声音测试录制已验证。
- 2026-09-19 已用真实浏览器与隔离后端验证字幕跟随/手动浏览、单句循环/倍速、全屏、保留时间轴校稿、历史恢复、另存口播稿及回收站恢复，共 7 条流程。公开脚本为 `tests/creator-workflow.mjs`，需先构建界面并安装项目依赖、FFmpeg 和 Microsoft Edge；命令见 README。脚本使用合成视频和预置字幕，不验证识别准确率，也不使用个人资料库。
- 配音草稿及参数跨页恢复、素材库隐藏选中项隔离和媒体定位另做了隔离界面验证；配音参数持久化、字幕保护与恢复边界有 `tests/test_creator_safety.py` 回归测试。
- 飞书 OAuth、目录、多维表格、附件等流程有接口测试，但尚未使用真实账号完成全部写入验收。
- 公开抖音单篇素材下载与转录已验证；主页跨页测试遇到登录要求，未完成全量验收。
- B 站、YouTube 字幕在开发环境分别遇到连接错误和限流；不能保证每个平台、每条链接都可用。
- 麦克风及混合输入提供了实现，但尚未完成真实麦克风环境验收。
- 自动化接口通过不代表真实账号、网络和音视频质量均已验收。
