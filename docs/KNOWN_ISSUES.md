# 已知问题与功能范围

更新日期：2026-09-04。本项目为开发预览版，以下是已复现或已确认的限制，不表示已修复。

## 使用中需要注意

| 问题 | 当前行为 / 临时用法 |
|---|---|
| 配音页尚无草稿恢复 | 手动输入的配音正文切换页面后会丢失。生成前先在文稿库保存正文。文稿编辑和文案处理已有草稿机制。 |
| 批量选择跨文件夹保留 | 切换文件夹后，隐藏的选中项仍可能被移动、导出或移除。操作前检查已选数量，先取消原选择。 |
| 移除后没有界面恢复入口 | 目前是软删除，源文件保留，后端有恢复接口，但还没有回收站。重要资料请备份整个 data 文件夹。 |
| 下载完成和转录完成混用状态 | 只下载素材也可能显示已完成。链接素材可在主页采集页勾选后点击“转录所选”；提取页还缺少对应下一步动作。 |
| 编辑后搜索结果未及时更新 | 保存后重新输入搜索词可以刷新匹配结果。 |
| 单篇链接未去重 | 重复粘贴同一个链接会产生重复任务；主页采集有独立的去重逻辑。 |
| 批量操作每次最多 1000 条 | 主页采集上限虽然可选 10000 条，下载、导出等仍需分批选择。 |
| 文本服务兼容性 | 当前按 OpenAI Chat Completions 协议调用，在服务基地址后追加 /chat/completions。开发验证中有已配置服务返回 HTTP 405；尚无连接检测和协议适配引导。 |

## 尚未实现

- 音色克隆 / IndexTTS2：目前使用 Windows 系统语音。
- 实时直播录制、自动选取精彩片段：目前仅能按起止时间截取本地音视频。
- 真正从识别中断点续接：可以复用已下载文件，但重新开始会重新识别整段。
- 托盘后台运行：关闭主窗口会结束此次启动的后端。
- 独立安装器、自动更新、界面备份恢复。

## 真实环境验收范围

- 本地导入、真实中文语音转录、逐段编辑、常用导出、Windows 系统配音、本地切片及系统声音测试录制已验证。
- 飞书 OAuth、目录、多维表格、附件等流程有接口测试，但尚未使用真实账号完成全部写入验收。
- 公开抖音单篇素材下载与转录已验证；主页跨页测试遇到登录要求，未完成全量验收。
- B 站、YouTube 字幕在开发环境分别遇到连接错误和限流；不能保证每个平台、每条链接都可用。
- 麦克风及混合输入提供了实现，但尚未完成真实麦克风环境验收。
- 自动化接口通过不代表真实账号、网络和音视频质量均已验收。

反馈问题时建议提供：Windows 版本、应用版本、操作步骤、预期结果和去除敏感信息后的报错。不要在 Issue 中提交 API Key、App Secret、Cookie、账号资料或私人文稿。
