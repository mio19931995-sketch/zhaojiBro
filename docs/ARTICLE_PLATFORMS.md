# 文章图文与全屏阅读

「文案提取」共用链接输入框支持微信公众号、知乎、今日头条及小红书图文。文章不需要语音识别模型，也不调用配置的文本模型。

| 平台 | 单篇链接 | 获取方式 |
| --- | --- | --- |
| 微信公众号 | `mp.weixin.qq.com/s/...` 及完整分享参数链接 | 直接获取公开文章，详见 [公众号说明](WECHAT_ARTICLES.md) |
| 知乎 | `zhuanlan.zhihu.com/p/...`、`www.zhihu.com/question/.../answer/...` | 在独立平台窗口打开文章或单条回答 |
| 今日头条 | `www.toutiao.com/article/.../`、`.../i.../` | 在独立平台窗口打开文章 |
| 小红书 | `www.xiaohongshu.com/explore/...`、`/discovery/item/...`、`xhslink.com` 分享短链 | 在独立平台窗口打开图文；请保留完整分享参数 |

本轮接入单篇内容，不支持这些平台的主页、搜索页或文章列表批量采集。小红书分享内容若是视频笔记，则回到既有视频处理流程，不把它伪装成图文。

## 使用步骤

1. 粘贴完整分享链接，点击「抓取」加入队列。
2. 点击任务的「在平台窗口抓取」。在弹出的正常网站页面中完成必要的登录或安全验证；登录状态按平台保存在本机。
3. 正文加载后自动保存并关闭平台窗口。如果验证耗时较久，完成后使用顶部「返回原文」，再点「保存当前文章」。也可通过「登录平台」「重新加载」恢复加载失败的页面，或取消退出。
4. 完成后点「查看」→「原文」。原文保留文字、图片、字体字号、行距、颜色和段落结构；小红书多图可用「上一张 / 下一张」切换。
5. 点击「全屏浏览」进入 Windows 原生全屏。正文内滚动；按 Esc 或点击「退出全屏」返回。

「文稿」是可编辑的简体正文，支持导出、文案处理及「复制到 Codex」。图片中的文字不自动 OCR。「原文」保留源文字，独立于文稿编辑；「刷新图文」不会覆盖已编辑的标题与正文。「重新提取」成功替换前保留旧文稿历史，失败时保留已有文稿与快照。

更新代码并运行 `npm.cmd run build` 后，须完全退出再打开 Lulu，才能加载新的 Electron 和 Python 逻辑；只刷新界面不够。

## 排版及访问边界

保存的是可阅读的静态原文，不执行平台脚本。图片、CSS 和所需字体尽量下载到本地。评论、关注按钮、视频、登录组件等不属于正文快照。不同窗口尺寸下可能重排；动态图文、系统缺失字体及平台改版不能保证像素级一致。资源未能保存时，阅读器明确显示缺失数量和刷新入口。

平台窗口使用正常可见页面，不读取私有接口，也不绕过登录、验证码或付费限制。失效笔记、受限内容、网络异常仍可能无法抓取；验证页面不能作为正文保存。小红书签名参数过期时，请从平台重新复制完整分享链接。

窗口与主程序隔离：无 Node、无本机桥接、无外部下载权限；只允许留在对应平台。后端按平台检查图片、样式和字体的资源域名、跳转及公网地址。登录 Cookie 留在浏览器会话中，不发送给后端下载器或配置的模型。原文经静态白名单处理，在禁用脚本的 iframe 中显示。保存沿用每篇 240 个资源、128 MiB 总量等边界。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest tests/test_articles.py tests/test_article_archive.py tests/test_wechat.py -q
npm.cmd run build
node tests/platform-articles.mjs
node tests/article-reader.mjs
node tests/wechat-workflow.mjs
```

`platform-articles.mjs` 默认用合成网站页面验证真实 Electron 窗口、IPC、工作队列、本地图片解码、排版、多图切换、原生全屏与 Esc。不会读取正式资料库。

真实平台验收可设置 `LULU_ARTICLE_TEST_URL` 为自己的有效文章链接，再运行同一脚本；如果需要登录，须在测试窗口亲自完成。可通过 `LULU_ARTICLE_TEST_PROFILE` 指定专用测试浏览器配置目录以保留登录状态，该目录不能同时被另一个 Electron 实例使用。多篇验收使用 `LULU_ARTICLE_TEST_URLS` JSON 数组。不要使用正式程序的浏览器配置目录。

测试证据存放在忽略目录 `.test-data/platform-articles-*`；不提交原文、账号登录资料、分享令牌和截图。真实验证结果只代表所测文章与当时的访问条件；合成测试不能替代实际平台验收。
