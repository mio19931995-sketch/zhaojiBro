## 工具：官方实际集合与运行边界

`app/src/core/agent_workspace/tools.py:18` 注册 16 项应用内工具；`context.py:10` 另定义 3 项文稿编辑协议。它们不是任意 Python、终端、浏览器或外部 MCP 服务器执行器。

| 工具 | 官方实际行为 |
| --- | --- |
| `search_documents` | 本地文稿搜索，返回最多 20 个标题/编号，并将发现的 ID 记录到本轮 |
| `read_document` | 当前目标使用冻结范围；其他文稿只允许读取本轮搜索发现的 ID；每页 24000 字符，提供 next_offset |
| `read_targets` | 读取本轮冻结作用对象；官方有引用时只拼接引用，不能借此读取整篇未选正文 |
| `create_document` | 另建文稿，原文保持不变；以请求/调用 ID 生成幂等标识，read_only 时拒绝 |
| `list_tasks` | 仅当前会话最近 20 项任务的真实状态/结果编号，不读取其他会话或结果全文 |
| `inspect_link` | 本地识别链接和平台采集能力，不发网络请求 |
| `prepare_voice`、`prepare_transcription`、`prepare_collection` | 返回 needs_input 与对应工作台入口/参数；不直接下载、采集、转录或生成配音 |
| `load_skill`、`read_skill_reference` | 按需加载已启用技能及其包内 Markdown，检查冻结版本和显式调用限制 |
| `search_skills`、`prepare_skill_install` | 搜索本机系统/用户技能，或打开技能设置；没有互联网技能搜索 |
| `create_skill_draft`、`list_skill_drafts`、`install_skill` | 形成待安装包，列出预览，安装已预览 token 或系统技能；不能猜测未预览 token |
| `propose_edits`、`edit_document`、`resolve_proposal` | 官方结构化建议、直接文稿编辑、处理此前建议。Windows 第二阶段使用本地 diff 与显式按钮采纳，不能混称为同一个工具协议 |

`application.py:436` 的循环限制是累计最多 **8 次工具调用**，不是 8 个 HTTP 请求。执行前验证整个批次的工具集合、完整参数与唯一调用 ID，重复或未知调用不能先部分执行；完整 assistant envelope 与配对回执先校验后使用。运行中保留原始工具协议，跨轮通过 `tools.py:203` 转成普通历史资料，避免压缩或切换模型后留下孤立 tool_result。

同一错误连续出现两次会暂停；needs_input 会结束当前工具轮次，等待用户完成对应选择。工具失败和准备入口不能被显示为“已完成”。取消会在每次工具执行和最终发布之前检查，未执行的步骤不能在重启后自动继续。

官方 `context.py:118` 还把技能管理类工具限定为：加载 `find-skills` 后开放搜索/安装，加载 `skill-creator` 后开放创建/安装。v4.3.1 的随包目录没有这两项技能，用户需自行导入；Windows 若以可见工具开关代替此门槛，必须明确这是适配，不声称官方默认开放所有工具。

## 技能：生命周期与 Windows 差异

官方 `app/internal-skills/catalog.json` 只包含六个系统技能：`lulu-proofread`、`lulu-polish`、`lulu-voice`、`lulu-translate`、`lulu-summary`、`lulu-analysis`。`SKILL.md` 描述写作方法；它不授予工具权限，不执行包内脚本，不提供在线搜索、下载或更新能力。

| --- | --- | --- |
| `skill_manager.py:85`、`:110` | 文件清单摘要绑定整个包；SKILL.md 需 YAML 名称/简介及非空正文；包大小、单文件大小与数量有限制 | 保留原始内容与 Markdown 参考；不能只存简介后声称完整技能已导入 |

## 验收清单与待主任务补充的交付记录

- 自动阈值触发、手动压缩、两轮边界、完整日志保留、摘要失败/取消/迟到 CAS；旧会话无 checkpoint 可迁移。
- 文稿、引用、技能、schema、工具结果都计入预算；最低容量配置仍有有效输入额度；没有静默截断。
- 工具整批参数/ID 验证、8 步上限、关闭工具、跨会话/未发现 ID 拒绝、选区只读范围和 call/result 配对。
- 本地技能预览/安装/启停/卸载/恢复/导出；Windows ZIP 路径与大小边界；技能禁用或版本变化后的旧运行不能继续写入。
- 工作台 handoff 确实带入目标和参数，但点击入口本身不发起采集、转录或配音。
- 持久写入的确认结果、重复请求与取消状态一致；模型输出、摘要或技能内容不构成额外授权。
- 使用隔离资料库与合成资料做 Windows Electron 验收；真实云模型的容量/工具协议/输出质量及用户既有资料库仍需独立验证。

Windows 有以下明确适配：

- 默认工具关闭，兼容原有纯文本服务；开启后需服务支持 Chat Completions `tool_calls`。不支持时提示关闭工具或更换兼容模型，不静默降级。
- 使用可见的工具允许列表，替代官方 `find-skills/skill-creator` 的管理工具门槛。技能文本与历史摘要不能扩大允许列表；每次调用取本轮冻结权限与当前权限的交集。
- 原文修改继续使用第二阶段逐项建议与保存入口，没有开放官方三个直接编辑工具。当前技能方法会明确此差异，避免模型声称调用不存在的工具。
- 窗口默认 32768、压缩阈值 75%，容量可设 8192–2000000；输出额度为 `min(8192, window/4)`，并保留 5% 余量。显示的是估算，非服务端精确 token 数。完整近期轮次、技能或工具结果自身过大时明确失败，不截断。
- 包文件不会提取或执行。校验原 ZIP 文件名、大小写/Unicode 冲突、盘符/反斜杠/ADS/保留名、链接/特殊文件与体积限制；目录上传将浏览器选取的文件作为数据接收，不开放任意服务器文件路径。单包 16 MiB、最多 512 文件、单文件 1 MiB、SKILL.md/读取的 Markdown 256 KiB。
- 模型生成的新文稿标题、正文、技能简介和指令在预览前统一简体，并与确认内容绑定；用户导入包与只读引用保持原始内容。
- 卸载恢复优先用户保存的包；同名替换和版本恢复前都备份当前包。与官方“同包重复安装保持停用状态”不同，本实现用户主动重新安装同包会启用它，界面有独立停用按钮。

## 使用方法

更新后重启 Lulu。在“文案处理”中选择文稿，点击右侧“工具与技能”。

1. **上下文**：核对模型容量与自动压缩阈值，点击“保存上下文设置”。需要时点击“立即压缩”，可查看四类摘要；处理中可以取消。失败不会删历史或覆盖旧摘要，可以重试。
2. **工具**：勾选“启用工具调用”，选择需要的能力，保存设置。“启用常用工具”仅选择读取资料和准备入口；另存文稿等需要单独勾选。回到对话描述要求，查看真实工具结果；待确认卡点击“确认执行”才创建/安装。
3. **技能**：查看随包技能，或选择“导入技能包/文件夹”检查预览后安装；也可展开“编写新技能”生成待安装草稿。回到工作区在“本轮技能”选择，或用 `/技能名称 要求` 发送。技能的停用/卸载从后续验证立即生效。
4. **技能恢复**：已卸载条目可点击“恢复”。若曾替换内容，点“查看技能”，选择“技能历史版本”，检查正文后点“恢复此版本”；恢复前的版本同样保留。导出得到包含原 SKILL.md 和参考资料的 ZIP。
5. **工作台交接**：配音、转录和采集工具返回“前往…”按钮；打开后检查带入文字、链接、数量及音色/登录/模型，再主动开始。打开入口不会自动下载、抓取、转录或生成声音。
