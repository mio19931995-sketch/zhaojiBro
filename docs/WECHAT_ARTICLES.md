# 微信公众号文章提取

在「文案提取」粘贴 `mp.weixin.qq.com` 单篇文章分享链接，点击「抓取」，再点击任务的「开始」。支持短链接 `/s/文章标识` 和包含 `__biz`、`mid` 等参数的长链接。

旧版报 `Unsupported URL` 的公众号任务无需删除重建：更新代码、构建界面并完全退出重新打开 Lulu 后，直接点击该任务的「重试」。

## 提取结果

- 保存文章标题、公开可见正文、作者、公众号名称、发布时间和来源链接。「文稿」提供可编辑的简体文字；段落、换行、代码缩进及正文超链接会保留。
- 「原文」保留来源文章的文字、图片顺序、内联样式和样式表，下载正文图片及所需字体等资源供本地阅读。与可编辑文稿分开保存，不将应用的字体样式套到原文上；原文保留源页面文字，文稿仍输出简体中文。
- 在「原文」点击「全屏浏览」，可铺满屏幕阅读；点击「退出全屏」或按 Esc 返回，阅读位置保留。正文获得焦点后也可按 Esc。Windows 使用原生窗口全屏，普通浏览器使用 Fullscreen API。
- 旧文章点击「加载原文」补存图文；「刷新图文」只更新原文快照，不覆盖编辑过的文稿与标题。新版重新打开后才能加载新的主进程和后端逻辑，仅刷新页面不够。
- 勾选现有「封面文件」选项时尝试下载封面，封面失败不影响正文保存。没有修改任何下载、缓存或保留媒体的全局默认设置。
- 完成后可在任务队列或文稿库查看，编辑、导出 TXT/Markdown、进入文案处理；Markdown 附带作者与来源信息。
- 点击「复制到 Codex」，再到目标 Codex 对话手动粘贴。复制内容指定文章 ID，并指引 Codex 使用现有 Lulu MCP 分页读取正文；需要已连接 Lulu MCP。不会自动切换 Codex 项目、粘贴或发送。
- 「重新提取」成功替换前保存旧正文到历史版本；访问失败或暂停时保留当前正文。可在预览的「历史版本」恢复编辑过的内容。

公众号文章不经过视频下载器、不调用语音识别或付费文本模型；不要求安装转录模型。文章不包含视频文件或字幕时间轴，SRT 导出不可用。文稿库按文章展示作者、公众号与发布时间，不显示视频时长或未采集的互动指标。

## 边界与错误处理

暂不支持公众号主页批量采集、图片 OCR、内嵌音视频下载或付费隐藏正文。纯图片文章可以保留图文、在文稿库浏览，不伪造识别文字或时间戳；仅有视频而没有文字或图片的页面仍提示无法提取。

原文快照不执行源页面脚本，也不保留表单、播放器和交互组件。依赖微信脚本加载的动态内容、登录或验证页面可通过「在线原页」交给系统浏览器查看。不同窗口宽度下会按原文响应式样式重排；无法取得的字体由浏览器按原文字体栈回退，不能保证所有模板像素级一致。图片或样式未下载完整时显示缺失提示和图片数量，可以刷新重试，不会伪装成完整快照。

微信安全验证、频率限制、文章删除、非文章链接、空正文及网络错误分别提示原因。需要登录或验证时，请在微信中打开原文按平台要求操作后再试；这不保证后续公开请求能访问。仍受限时，可手动复制有权访问的正文，在文稿库「新建文稿」。程序不绕过访问限制；公众号抓取不使用或发送用户配置的 API Key、平台 Cookie。

仅请求公众号、微信图片和指定微信静态资源域名。每次跳转都检查域名与公网地址，拒绝本地地址、无效协议及带凭据地址。网页最多 8 MiB、封面最多 4 MiB；原文单个图片/字体最多 16 MiB、合计最多 128 MiB、最多 240 个，样式最多 40 份、每份 2 MiB。图片和样式表并行获取，短暂网络传输故障重试一次。只获取正文实际使用的 CSS 图片资源，避免被整套微信表情图标拖慢。

HTML 经过白名单处理，在禁用脚本的 iframe 中展示，另有独立 CSP 限制为当前文章的本地资源。快照位于程序数据目录的 `articles/<素材ID>/<版本>/`；每次成功刷新产生新版本，失败或暂停保留已有快照。原文是只读浏览，资源清单不直接对外提供。TXT/Markdown 仍是文字导出，不是包含所有图片的网页导出。

## 实现位置

- `backend/wechat.py`：链接识别与规范化、有界获取、正文解析、封面及历史保护。
- `backend/article_archive.py`：静态原文快照、样式解析及图像/字体资源保存。
- `backend/main.py` / `backend/engine.py`：新链接入队、旧任务重试与重新提取，文章在 yt-dlp/ASR 之前分流。
- `src/App.tsx` / `src/Inspector.tsx` / `src/Library.tsx`：共用输入、文章任务、来源信息与文稿库展示。
- `src/ArticleReader.tsx` / `electron/main.cjs`：原文阅读、全屏、退出和焦点处理。
- `backend/codex_connection.py` / `backend/codex_bridge.py`：准确的文章引用、来源信息和纯文稿读取说明。
