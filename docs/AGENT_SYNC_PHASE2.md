## 状态约束

- 引用：当前可用 → 文稿编辑后陈旧 → 显式移除/重新选择。仅凭文字仍然相同不能证明原版本未变。
- 建议：pending → partly_applied → applied；放弃只处理仍 pending 的操作；新方案可将旧方案未处理部分标记 superseded。每项都有独立状态，不能由模型文字决定已经保存。
- 部分应用：在同一事务中保存正文、历史、建议状态和剩余范围；同一次请求重试不新增历史或重复替换。
- 外部编辑：正文、标题、时间轴或工作区基线变化后拒绝覆盖。结果可以继续查看或另存，不能自动把旧建议“猜测匹配”到新文本。
- 撤销：只撤销仍为当前最新写入的操作；发生后续编辑时保留新内容，转向历史比较恢复。
- 文稿切换：未完成请求、引用、结果归属均以文稿/会话 ID 核对；陈旧异步响应不得覆盖当前窗口。

## 本轮 Windows 实现映射（静态核对）

1. `src/AIWorkbench.tsx` / `src/aiWorkspaceTypes.ts` 区分“仅处理选中片段”和“引用选中片段”：前者限制本轮修改范围，后者是只读参考；还可从其他文稿添加只读参考。浏览器 UTF-16 选区转换为 UTF-8 字节范围。当前选择在本地持久保存，参考内容及版本由服务端保存；原文变化后需要重选。
2. `backend/ai_workspace.py` 将当前正文、选区和参考素材冻结到 run。`backend/ai_edits.py` 根据模型完整返回文本与输入文本生成本地差异，范围由本地算法计算，不采信模型偏移。这是适配现有文本模型接口的方案，没有迁移官方结构化工具调用循环。
3. `src/AIAgentTools.tsx` 展示每项原文/建议，提供逐项“采纳到草稿”“忽略”“撤销最近采纳”。本轮没有一次多选应用。建议状态为 `pending / accepted / dismissed / reverted`；旧 run 仍可查看和另存，但不能应用到当前草稿。
4. 采纳/撤销只更新工作区草稿，使用数据库事务、不可变输入、当前基线和采纳顺序保护部分编辑。它们不会立即修改来源文稿或新增来源历史。用户点击“保存文稿”后才走原有来源写入和历史快照机制；有字幕时阻止改变行结构的逐项采纳，保留时间轴及发言人字段。
5. 撤销仅限草稿仍处于当前 run 的受控版本；正文/标题改变、来源变化、有其他来源草稿，或保存代次变化后拒绝旧结果写入。保存后的恢复使用现有历史版本入口，不把“撤销最近采纳”作为恢复已保存来源的按钮。

以上映射由已落盘源码确认，尚不代替功能验收。隔离测试、Windows Electron 实机和真实平台/模型验证结果由主任务记录。

官方 v4.3.1 常规明确改稿可调用 `edit_document` 直接写入，`propose_edits` 用于先讨论方案；官方 `workspace.js:856` 的方案区主要展示结果，决策也可以经自然语言工具调用完成。Windows 本轮以显式确认按钮完成应用，是针对现有应用的交互适配，不能称为官方全部 Agent 行为的直接复制。

## 验收需要覆盖的真实风险

- 相同句子出现两次，仅替换选中的第二次；中文和 emoji 前后选区不得错位、切断 surrogate 或 UTF-8 多字节字符。
- 新文字比原文长/短时，先采纳前项再采纳后项，以及反向顺序都正确。
- 生成期间编辑原文、已有未保存来源草稿、另一个会话保存、外部改标题或时间轴，均不得被旧建议覆盖。
- 同一应用请求重试幂等；放弃项不能采纳；其他会话不能应用本会话结果；恶意/越界/重复目标响应不发布可执行建议。
- 保存正文、历史和状态必须全成功或全失败；字幕结构变化应明确阻止写回并允许另存。
- 最新应用可以撤销；之后有编辑则拒绝撤销；部分应用后下一项仍可继续；取消或关闭后的迟到模型响应不能创建已完成/已应用状态。

## 使用与本地复现

更新完成后关闭并重新打开 Lulu，使 Python 后端与前端一起加载新版本；不要在转录或录制过程中强制结束进程。

1. 从文稿预览点击“继续处理”，或进入“文案处理”选择已有文稿。
2. 在左侧正文中选中一段，点击“仅处理选中片段”。右侧会明确显示本轮范围；想处理整篇时点击“处理全文”。片段范围随对话保留，正文版本变化后必须重新选择，不会偷偷改为处理全文。
3. 可用“引用选中片段”或“添加参考素材”提供背景资料。引用只读，可查看、定位草稿引用或移除；最多 8 条、合计 16000 字符，超出时提示重新选取，不截断。外部文稿可引用全文或一段。
4. 输入要求并发送。结果中的“逐项建议”提供原文/建议对照、“定位原文”“采纳到草稿”和“忽略”；可撤销最近一次采纳，继续处理其余建议。
5. 确认左侧草稿后点击“保存文稿”。来源历史保留，时间轴和发言人字段按原字幕行对应。改变字幕行结构的建议会阻止采纳；可另存独立输出。保存后恢复旧稿使用原有“历史版本”。

正文、标题、来源版本或保存状态变化时，旧建议和旧撤销会被拦截。已经采纳或忽略过部分建议的结果不能再通过“应用到文稿”全文覆盖。外部引用变化后须移除或重新添加，发送前不会静默刷新内容。
