# Agent 真实模型验收（2026-10-26）

使用本机当前配置的 **Agnes `agnes-3.0-flash`**、实际 `apihub.agnes-ai.com` 服务和已有密钥验证。配置通过只读方式读取，凭据仅保留在内存；应用路由、技能加载、工具执行和模型 HTTP 响应均走真实实现。测试文稿、技能、历史、待确认动作和新建结果全部放在独立临时资料库，没有读写用户素材或修改生产设置。

本次明确区分真实云服务验收与原生桌面离线回归：前者使用应用 API 和真实模型，后者使用 Windows Electron 与本地模拟服务。没有把模拟回复计作真实模型通过。

## 实测发现与修复

1. **Agnes 工具响应被拒绝**：服务在 `stream:false` 的 `tool_calls` 中也带有 `index`。旧的严格结构校验拒绝该字段，实际工具完全未执行。现在仅移除经过非负整数检查的这一位置元数据，随后继续执行原有工具名、参数、调用 ID、权限、批次和数量校验；下一轮 assistant/tool 消息使用标准结构。未知字段、异常 index 和未授权工具仍拒绝整批执行。
2. **检索查询不匹配实现**：模型曾把“标题包含…的文稿”整句传给子串搜索。工具说明现在明确 query 应使用短关键词，并说明匹配标题和正文、可缩短词重试。复测实际传入关键词并找到目标。

## 仍存在的真实模型限制

- **中文品牌名翻译不可靠**：内置翻译技能能生成英文、保留测试中的数值及日期，但模型曾将“松果X1”改为英文词或拼音形式，甚至在要求保留原名时仍改写。仅加强系统方法说明的尝试未稳定解决，因此没有把提示词改动当作修复提交，也不将该项标为通过。需要在应用预览中人工校正专名；本轮未引入术语锁定或严格语义校验，不能承诺任意文稿都不误改。
- **服务暂时错误**：测试期间出现两次 HTTP 500，服务消息为 rate-limit 检查失败。应用保持原文和完整对话，返回服务暂不可用；后续重试恢复。没有自动切换服务或修改用户密钥/配置。
- 此次证明 Agnes 的上述路径可以运行，不代表 16 项工具、所有技能、其他提供方、实际最大容量、弱网取消和任意输出质量均已实测通过。
